Built a comprehensive workforce management platform at PTW, serving global teams with scheduling, resource allocation, and operational insights.

## Challenge

PTW needed a centralized system to manage workforce scheduling across multiple time zones, track resource utilization, and provide real-time operational visibility to managers.

## Solution

Designed and built a full-stack application with React frontend and Django REST backend. The system features real-time dashboards, automated scheduling suggestions, and role-based access control.

## Key Contributions

- Architected the Django REST API with modular service layer for scheduling logic
- Built responsive React dashboard with real-time updates via WebSocket
- Implemented Celery task queue for async report generation and notification delivery
- Set up Docker-based development and deployment pipeline
- Designed PostgreSQL schema optimized for time-series scheduling queries

## Impact

- Reduced manual scheduling effort by automating conflict detection and suggestion engine
- Provided real-time visibility into workforce utilization across regions
