Built an analytics dashboard at Fractal that provides real-time visibility into operational KPIs and ML model performance metrics.

## Challenge

Data science teams needed a unified view of model performance, data drift, and operational metrics — replacing scattered notebooks and manual reporting.

## Solution

Designed a Vue.js dashboard with FastAPI backend that pulls data from multiple sources, computes metrics, and renders interactive visualizations.

## Key Contributions

- Built Vue.js frontend with Chart.js for interactive data visualizations
- Designed FastAPI endpoints for metric aggregation and time-series queries
- Implemented ML model monitoring: accuracy tracking, data drift detection, prediction distribution analysis
- Created configurable alert system for metric threshold breaches
- Optimized PostgreSQL queries for large time-series datasets

## Impact

- Consolidated model monitoring into a single pane of glass
- Enabled proactive detection of model degradation through automated drift alerts
